# NumericalMethods

## Overview
A collection of numerical algorithms and simulations implemented entirely from scratch in Python. These projects were developed as part of the **Numerical Methods** coursework at **Gdańsk University of Technology (Politechnika Gdańska)**. 

## Technologies
* **Python**
* **NumPy** (for efficient matrix and vector operations)
* **Pandas** (for data manipulation and loading)
* **Matplotlib** (for data visualization and convergence analysis)

## Projects Directory
Each project is housed in its own subdirectory containing the source code, datasets, and a dedicated `README.md` with a detailed analysis and key findings. 

### [1. MACD Indicator: Algorithmic Trading](./MACD_Indicator)
Implementation of the MACD (Moving Average Convergence/Divergence) indicator. This project simulates an automated trading strategy on historical financial datasets, calculating exponential moving averages recursively to generate buy/sell signals and evaluate portfolio profitability.

### [2. Systems of Linear Equations Solvers](./Solving_Systems_Of_Linear_Equations)
A comparative analysis of iterative methods (Jacobi, Gauss-Seidel) versus direct methods (LU Factorization) for solving large systems of linear equations (`Ax = b`).

### [3. Elevation Profile Interpolation](./Elevation_Profile_Interpolation)
An exploration of data interpolation techniques applied to real-world GPS elevation profiles. This project compares Lagrange Polynomial Interpolation against Cubic Spline Interpolation to reconstruct smooth topographical curves from discrete data points.
